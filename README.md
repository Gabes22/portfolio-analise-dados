# 📊 Portfólio de Business Intelligence: Python & Power BI

Este repositório contém um projeto completo de Análise de Dados e BI que integra automação em **Python** para engenharia de dados e **Power BI Desktop** para visualização e storytelling corporativo. 

O objetivo deste projeto é demonstrar a capacidade de extrair, estruturar e transformar dados brutos de diferentes domínios de negócios em dashboards interativos e profissionais.

---

## 🛠️ Tecnologias Utilizadas
* **Python** (Bibliotecas: `Pandas`, `NumPy`) — Geração, simulação e tratamento de massas de dados.
* **VS Code** — Ambiente de desenvolvimento para os scripts em Python.
* **Power BI Desktop** — Modelagem e criação dos relatórios visuais.
